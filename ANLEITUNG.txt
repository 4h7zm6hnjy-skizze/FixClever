WICHTIG VORAB
- Bestehende lokale Profile und Testergebnisse möglichst vorab in FixClever exportieren.
- Nichts aus dem alten Repository löschen.
- Der GitHub-Connector verweigerte bisher direkte Änderungen (HTTP 403): Das Paket ist
  vorbereitet, aber NICHT automatisch auf GitHub installiert.
- Das ZIP ist ein UPDATE, keine vollständige Kopie der bestehenden 3,9-MB-Inhaltsdatei.

SO WIRD DAS GESAMTUPDATE EINGESPIELT
1. ZIP herunterladen und ENTpacken (nicht die ZIP selbst in GitHub hochladen).
2. GitHub-Repository öffnen und auf „Add file“ > „Upload files“ gehen.
3. Die folgenden Dateien aus dem entpackten Paket direkt in das HAUPTVERZEICHNIS
   des bestehenden Repositorys hochladen; gleichnamige Dateien ersetzen:

   fc231-tests.js       – kompatibler Testcode plus automatische 3.0-Modul-Einbindung
   fc300-suite.js       – alle neuen Lernfunktionen
   fc300-style.css      – responsives Zusatzdesign
   sw.js                – neuer Offline-Dienst
   version.json         – Release 3.0.0
   manifest.webmanifest – PWA-Metadaten 3.0.0
   update-check.js      – entfernter Altversions-Widerspruch (Fallback)
   repair.html          – Start- und Cache-Reparatur
   diagnose.html        – veröffentlichte Datei-Prüfung
   prepare-index.html   – Generator für die aktualisierte index.html

4. Commit changes bestätigen, GitHub-Pages-Veröffentlichung abwarten.
5. Danach IM SAFARI folgende Seite öffnen:
   https://4h7zm6hnjy-skizze.github.io/FixClever/repair.html
   Auf „FixClever öffnen“ klicken. Das 3.0-Lerncockpit wird über fc231-tests.js geladen.
6. Für die statische 3.0-Versionsanzeige zusätzlich aufrufen:
   https://4h7zm6hnjy-skizze.github.io/FixClever/prepare-index.html
   Auf „Angepasste index.html erstellen“ tippen. Die heruntergeladene index.html
   anschließend in GitHub als Ersatz für die ALTE index.html hochladen.
   Dies ändert nur Start-Metadaten und eine Vorladeregel, NICHT die Lerninhalte.
7. Nochmal die Reparaturseite öffnen; danach die App starten.
8. Abschließend Diagnose aufrufen:
   https://4h7zm6hnjy-skizze.github.io/FixClever/diagnose.html
   „Prüfung starten“ tippen, ggf. Fehlerbericht kopieren.

HINWEISE
- Alle bisherigen Lernmodule bleiben im Repository; keine Datenbank wird migriert.
- Die lokalen Kinderprofile werden nicht bewusst gelöscht oder zurückgesetzt.
- Alte Testfragen bleiben bestehen; keine automatisch erfundenen Antwortoptionen.
- Arbeitsblätter: iPhone → Druckansicht → Teilen oder Drucken → als PDF sichern.
- Sprachausgabe und volle Offline-Nutzung hängen vom Browser ab.
- Die große Inhaltsdatei wurde NICHT aufgeteilt. Das bleibt eine nachweisbare
  strukturelle Grenze bei Startzeit und Mobilgeräte-Leistung.
- In diesem ZIP sind keine vollständigen NRW-Lehrplanprüfungen oder alle
  3.100 manuell fachlich überprüften Erklärungen enthalten.

Für genaue technische Einschränkungen PRUEFBERICHT.md lesen.
