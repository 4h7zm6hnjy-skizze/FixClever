FixClever 2.2.0 – Gesamtupdate (Lernzentrale)

INSTALLATION
1. ZIP entpacken.
2. Auf GitHub (4h7zm6hnjy-skizze/FixClever) in main hochladen:
   - index.html
   - sw.js
   - manifest.webmanifest
3. Diese drei vorhandenen Dateien ersetzen und den Commit abschließen.
4. FixClever online öffnen; auf die Bereitmeldung für den Offline-Cache warten.
5. Offline-Start anschließend im Flugmodus über das Home-Bildschirm-Symbol testen.

NEU: Lernzentrale (Lerncoach, Übungstrainer, Spiele, Wiederholungen, Statistik, Elternbereich, Lehrplan-Navigator, Datensicherung), zusätzliche Schulbuch-Hilfe und kleinere Antwortauswahl für Klasse 1–4.
Die bisherigen 3.100 Lerneinheiten und Profile werden unverändert übernommen.

WICHTIG: Der Lerncoach ist regelbasiert, nicht KI-gesteuert. Die neuen Trainer sind
eine erste Aufgabensammlung, keine vollständig überarbeitete Fachdatenbank.
Ein lückenloser Abgleich aller NRW-Kompetenzen sowie die fachliche Prüfung aller
bisherigen Tests sind nicht abgeschlossen.

Bitte vor größeren Änderungen im Eltern-/Backup-Bereich eine Datensicherung erstellen.
Das Löschen einer installierten Web-App unter iOS kann lokal gespeicherte Daten löschen.
NRW-Quelllinks und das Suchen nach Updates benötigen weiterhin Internet.
